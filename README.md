# SimpleTodoApp (ArrayList版)

Javaで作成したシンプルなToDo管理アプリです。

## 概要
コンソール上でやること（ToDo）を追加・表示・削除できるアプリです。  
配列版の実装を発展させ、ArrayListを使用することでより柔軟なデータ管理を実現しています。

## 機能
- やることの追加
- やること一覧の表示
- やることの削除
- メニュー選択式の操作

## 使用技術
- Java
- ArrayList
- Scanner（コンソール入力）

## 学習ポイント
- 配列とArrayListの違いの理解
- リスト操作（追加・削除・表示）
- 基本的な条件分岐とループ処理
- コンソールアプリの構造理解
