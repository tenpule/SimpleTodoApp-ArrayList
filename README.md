# SimpleTodoApp (ArrayList版)

Javaで作成したコンソールベースのToDo管理アプリです。

## 概要
コンソール上でToDoの追加・表示・削除・編集ができるアプリです。  
配列版から改良し、ArrayListを使用することで要素数の制限をなくし、柔軟にデータを管理できるようにしました。

## 機能
- ToDoの追加
- ToDo一覧の表示
- ToDoの削除
- ToDoの編集（内容の更新）
- メニュー選択式の操作
- 入力値のバリデーション（数値チェック・範囲チェック）

## 使用技術
- Java
- ArrayList
- Scanner

## 工夫した点
- 不正な入力（数字以外）を防ぐために `hasNextInt()` を使用
- 存在しない番号が入力された場合のエラーハンドリングを実装
- `nextLine()` を適切に使用し、入力のバグを回避
- ユーザーが直感的に操作できるようにメニュー形式で実装
